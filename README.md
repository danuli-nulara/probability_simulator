 # Probability Simulator

A beginner-friendly Python project that demonstrates randomness, probability, statistics, and data visualization using simulations.

## Features

### Coin Flip Simulator
- Simulates any number of coin flips.
- Displays:
  - Number of Heads and Tails
  - Experimental Probability
- Generates:
  - Bar Chart
  - Pie Chart
---

### Dice Roll Simulator
- Simulates rolling a six-sided die any number of times.
- Displays:
  - Frequency of each face (1–6)
  - Experimental Probability
- Generates:
  - Bar Chart
  - Pie Chart

---

###  Random Number Generator
- Generates random integers within a user-defined range.
- User chooses:
  - Minimum value
  - Maximum value
  - Number of random values
- Displays the generated numbers.

---

##  Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/probability-simulator.git
```

Install the required library:

```bash
pip install matplotlib
```

Run any file individually:



